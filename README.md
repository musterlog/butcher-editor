# Butcher Hero Save Editor

Edit your Butcher Hero save file (`game_data.bin`) right in your browser — on
phone or desktop. No PC tools, no app, no root. A single self-contained HTML page.

## Features
- **Load → edit → download.** Automatically recalculates the save's integrity
  hash, so the game accepts the edited file.
- **Editable values:** gems, all souls & materials, VIP points, No Ads, Soul
  Pass, Crystal Pass, Chaotic Soul, Island Pass 1–5, event booster tokens.
- **Resets:** VIP daily-chest cooldown, monster/tree spawners.
- **Shortcuts:** one tap for *all purchases + 9,999,999 gems* or
  *all materials to 999,999,999*.
- **Promo codes:** a 6-month daily code list that detects your time zone,
  shows the currently valid codes with a live countdown, and refreshes itself.

## How to use
1. Open the page.
2. Tap **Select game_data.bin** and pick your save.
3. Change the values you want.
4. Tap **Download edited save** and replace the game's `game_data.bin`
   with the downloaded file.

> **Back up your original save first.**

## Privacy
Your save file is **never uploaded** — all processing happens locally in your
browser, and the page works fully offline.

## Compatibility
Built for Butcher Hero **2.1**. A future game update may change the save format
or promo-code system and break compatibility.

## Disclaimer
For personal, offline use only. Use at your own risk.
